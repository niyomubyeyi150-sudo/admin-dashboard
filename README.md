## How I Customized Tailwind

For the CattleTrack project, I customized Tailwind CSS to create a consistent, modern design that reflects the agricultural and livestock management theme of the platform. I used a custom color palette with green shades to represent nature, growth, and farming, while neutral colors help maintain readability and a clean interface. I also customized the dark mode variant to support different viewing preferences and maintain consistent styling across the application.

To make the code more reusable and easier to maintain, I used Tailwind's `@apply` directive to group frequently used utility classes into custom CSS component classes. This reduces repetition and keeps the stylesheet organized. For example, common button styles, cards, and navigation elements can share the same spacing, colors, borders, and hover effects without repeating many utility classes in the HTML.

These customizations helped me maintain a consistent visual identity, simplify styling, and build a responsive interface that is easier to update as CattleTrack grows.
